# PLAN5 End-user UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the test-harness UI with a polished end-user UI: a split-screen login with configurable banner, help text and support email; a clean cluster list; a friendly "kagent unavailable" screen; and a chat page with a sidebar of past kagent conversations that can be resumed from any browser.

**Architecture:**
- Pages stay server-rendered by Go `html/template` with embedded static files.
- A new `internal/history` package reads kagent's session REST API through Rancher and normalises a session's tasks into a transcript. `chat.js` fetches that transcript as JSON and draws it with the same renderer it uses for live SSE replies.
- Tool calls and results are parsed once in `internal/a2a` and shared by the live chat and the history code.
- Agent Markdown is rendered by a hand-written `markdown.js` that builds DOM nodes only.

**Tech Stack:** Go 1.x stdlib (`net/http`, `html/template`, `embed`), plain ES2017 JavaScript with no dependencies, and `node --test` for the Markdown unit tests (Node 18+, already on CI runners).

**Spec:** `docs/superpowers/specs/2026-11-23-ui-polish-design.md`. Read it before any task; section numbers below refer to it.

## Global Constraints

- **No commits.** The user's global rule is "NEVER commit on behalf of user". Each task ends by running the tests and listing the changed files; the user commits.
- CSP stays exactly `default-src 'none'; script-src 'self'; connect-src 'self'; style-src 'self'; img-src 'self'; form-action 'self'; frame-ancestors 'none'; base-uri 'none'` (`wantCSP` in `server_test.go` must not change). No inline `<script>`, no `style=""` attributes, no external URLs. Inline `<svg>` in templates is allowed.
- Agent and tool text reaches the DOM only via `textContent` or `createTextNode`. `innerHTML`, `outerHTML`, `insertAdjacentHTML` and `document.write` must not appear anywhere in `internal/web/static/`.
- The portal sends kagent no `X-User-Id` header and no `user_id` parameter (spec §7.4, "Shared history").
- Colour tokens: `--navy #0f172a`; slate `#f8fafc #f1f5f9 #e2e8f0 #cbd5e1 #94a3b8 #64748b #475569 #334155`; accent `#2563eb`; ok `#15803d`; error `#b91c1c`; amber warning (`#fef3c7` background, `#78350f` text); info (`#eff6ff` background, `#1e3a8a` text). Font: the `system-ui` stack.
- Caps: tool result text 64 KiB, args 8 KiB, each followed by `\n… (truncated)` when cut. Banner 300 chars, login help 2000 chars. Conversation list: 50 entries.
- No debugging detail on any page: no SSAR, HTTP codes, token IDs or latencies. The one exception is the unavailable screen's `Reference: <outcome> · <cluster name>` line.
- `go vet ./...`, `go test -race ./...` and `node --test internal/web/jstest/` all pass at the end of every task.

## Review Focus

1. **Hostile agent text.** Markdown links with `javascript:`/`data:` URLs, raw `<script>` or `<img onerror>` in text, and HTML inside code fences must all appear as literal text. Covered in Task 9 tests.
2. **Huge or odd tool output.** A multi-MB tool result in a stored task, or a `function_response` with neither `content` nor `result`, must give a truncated or JSON-dumped result, not a failed page. Covered in Task 2 and Task 4 tests.
3. **Messy session lists.** A kagent session with no `name`, a null or unparseable `updated_at`, or more than 50 entries must still render (fallback title, no time, capped list). Covered in Task 4 tests.
4. **Bad `?c=` values.** Non-UUID, empty or repeated `c` parameters must not reach kagent. The page redirects to the clean cluster URL. Covered in Task 7 tests.
5. **Site count other than three.** With one configured site the home page shows no site chips. With four sites it shows "All sites" plus four chips, and an unknown `?site=` falls back to all sites. Covered in Task 6 tests.

**Interfaces:**
- Produces:
  ```go
  // rancher
  // GetJSON GETs path (already escaped) with the bearer and decodes the 2xx body into out, reading at most limit bytes.
  func (c *Client) GetJSON(ctx context.Context, bearer, path string, limit int64, out any) error

  // ranchertest.FakeCluster new fields
  Sessions      []FakeSession // pre-seeded conversations
  SessionStatus int           // if non-zero, every /api/sessions* route returns this code
  type FakeSession struct { ID, Name, AgentID string; Updated time.Time; TasksJSON string } // TasksJSON = raw `data` array
  // The fake also appends a FakeSession per new contextId on each A2A chat (AgentID "<agentns>__NS__<agent_name with - replaced by _>"),
  // Name = first 20 runes of the first message + "..." if longer, TasksJSON built from the DefaultChat turn (user text, one function_call
  // call_1 k8s_get_resources, its function_response, final text) with status.state "completed".
  // Routes (under .../services/<svc>/proxy): GET api/sessions/agent/{ns}/{name}, GET api/sessions/{id}/tasks; wrapped {"error":false,"data":...}.
  // Unknown session id -> 404 {"error":true,"message":"not found"}.

  // history
  var ErrNotFound, ErrExpired, ErrForbidden = errors.New("history: not found"), errors.New("history: expired"), errors.New("history: forbidden")
  type Conversation struct { ID, Title string; Updated time.Time } // Updated zero if unparseable
  type Item struct { Kind, Text, ID, Name, Args, Summary, Result string; IsError bool } // json: kind,text,id,name,args,summary,result,is_error (omitempty)
  type Turn struct { User string; Items []Item; State string }   // json: user,items,state
  type Transcript struct { Turns []Turn; Running bool }          // json: turns,running
  type Service struct{ /* clients, kagent cfg, maxDuration, now */ }
  func New(clients []*rancher.Client, k config.KagentConfig, maxDuration time.Duration) *Service
  func (s *Service) List(ctx context.Context, sites []auth.SiteResult, row clusters.Row) ([]Conversation, error)
  func (s *Service) Transcript(ctx context.Context, sites []auth.SiteResult, row clusters.Row, id string) (Transcript, error)
  func Normalise(tasksJSON []byte, now time.Time, maxDuration time.Duration) (Transcript, error)
  ```
- Rules (spec §7.4):
  - `List`:
    - Calls `.../proxy/api/sessions/agent/<agent_ns>/<agent_name>` and unwraps `data`.
    - A kagent 404 gives an empty list with nil error.
    - Takes the first 50 entries, keeping kagent's order (newest first).
    - The title is `name`, or `"Conversation · " + Updated.Format("2 Jan 2006")`, or `"Conversation"` when there is no time.
    - Timestamps are parsed with `time.RFC3339Nano`.
  - `Transcript`:
    - Requires `id` to appear in `List`, otherwise `ErrNotFound`.
    - Then calls `.../api/sessions/<id>/tasks` with a 16 MiB read limit, then `Normalise`.
  - Errors: Rancher 401 maps to `ErrExpired`, 403 to `ErrForbidden`, 404 on tasks to `ErrNotFound`. Others are returned wrapped.
  - The bearer comes from the `SiteResult` for `row.Site` with `StatusOK`; no such site gives `ErrExpired`.
  - `Normalise`, per task in order:
    - Dedupe `history` messages by `messageId`.
    - The first `role:"user"` text becomes `Turn.User`.
    - Each agent part in order becomes an Item: text gives `{Kind:"text"}`; `function_call` gives `{Kind:"tool", ID, Name, Args: FormatArgs, Summary: ArgsSummary}`; `function_response` fills `Result`/`IsError` on the tool item with the same `ID` (if there is none, append a tool item).
    - Skip parts whose metadata has `*_thought == true`.
    - If no agent text item exists, append the artifact text as a text item.
    - `State` is `status.state`.
  - Running and unfinished turns:
    - `Running = true` only if the **last** task's state is `submitted` or `working` **and** `now - status.timestamp < maxDuration`.
    - Any other task in those states gets an extra `{Kind:"notice", Text:"This reply didn't finish."}`.
    - `input-required` adds a notice: "The agent asked for approval, which the portal doesn't support yet."
